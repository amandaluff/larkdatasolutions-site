## Website

- Static HTML hosted on GitHub Pages from the `docs/` folder. Domain: www.larkdatasolutions.com.
- Pages are generated by `src/build.py` (shared header, footer, SEO tags, structured data). Edit `src/build.py` or `src/policies_body.html`, then rebuild:
  `python3 src/build.py docs`
- Preview locally: `python3 -m http.server 8420 --directory docs`, then open http://localhost:8420
- The logo is being redesigned. The current brand mark (`docs/assets/img/mark.svg`, favicons, `og-image.png`) is a placeholder.
- Never commit or push without the owner's clear yes.
